The implementation uses [jsonc-parser](https://github.com/dprint/jsonc-parser) (MIT) to retain comments and trailing commas. See [CLI task instructions](CLI.md#git-review-and-host-configured-buildtest-jobs) for exact supported fields, approval semantics and limitations.

Tasks execute with host privileges and are not sandboxed or editor-journal transactions. Approval pins the resolved executable and its bytes, arguments, cwd and resource limits; it does not freeze source code, dependencies, environment, or the behavior of the program. Tool-call approval remains separate from the stored project authorization.
