The checks use actual MCP requests and disposable local bare remotes for dirty worktree preservation, branch creation/switching, first push/upstream, fast-forward push, divergent push rejection, non-force branch-only fetch, stale and mismatched reviews, linked worktrees, protected/symlink paths and ignored-file overwrite rejection, executable hook and signing refusal, restrictive live access revocation, and redaction of a synthetic credential-bearing URL. The remote-state checks are independent host Git reads. No real hosted network, SSH connection, interactive credential helper or normal host prompt was tested.

Git and configured credential/SSH helpers are not sandboxed. Network streams are withheld to avoid exposing credentials, and a timeout or upstream setup error may follow a successful push. Custom fetch mappings, mirror, tags, pruning, recursive submodules, signed pushes and selected executable hooks and configured fsmonitor are refused. Branch switches reject protected paths, symlinks, submodules and changed `.gitattributes`; see [CLI guidance](../../CLI.md#git-review-and-host-configured-buildtest-jobs). Git cannot lock arbitrary non-Git filesystem writers, and FFSAKE does not claim an atomic remote snapshot.
