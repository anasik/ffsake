# FFSAKE v0.1.0-alpha.1

First public alpha candidate. FFSAKE is complementary tooling: native editing
stays the default, while FFSAKE adds scoped reads, one-call debugging, optional
reviewed and journaled edits, selective semantic operations, and MCP-only
capabilities such as Git review and project tasks.

## Highlights

- **CLI-first setup with optional MCP.** `configure --cli-first` installs
  project guidance and a Claude read hook or OpenCode read plugin, and keeps the
  MCP server registered for Git, tasks, access grants and persistent debug
  sessions. Existing host settings are preserved.
- **Reviewable edits.** Preview writes nothing; apply rechecks content and
  stale state; applied changes form one journal transaction with undo/redo.
  Native host edits remain outside this journal.
- **Debugging.** One-call and multi-stop `ffsake probe`, with debugpy and
  netcoredbg launch validated locally. Adaptors are not bundled.
- **Selective language intelligence.** Rust and C++ references, definitions,
  symbols, diagnostics and rename proposals through installed language servers.
  The one-shot CLI can preview and apply a semantic rename with source-hash
  guards. Macro-expanded, `cfg(test)`, integration-test and dependency code can
  be outside the snapshot; always run the project build and tests.
- **Straightforward lifecycle.** Review/apply configuration, `doctor
  --cli-first`, explicit updates with retained rollback generations, project
  removal that preserves unrelated settings, and binary uninstall.

## Install

Release archive (after the alpha is published):

```sh
git clone --depth 1 https://github.com/anasik/ffsake.git "$HOME/.local/src/ffsake"
python3 "$HOME/.local/src/ffsake/scripts/ffsake_install.py" install
python3 "$HOME/.local/src/ffsake/scripts/ffsake_install.py" \
  configure --host claude --project "$PWD" --cli-first --apply
python3 "$HOME/.local/src/ffsake/scripts/ffsake_install.py" \
  doctor --host claude --project "$PWD" --cli-first
```

Source fallback until the release exists:

```sh
python3 "$HOME/.local/src/ffsake/scripts/ffsake_install.py" install --source --profile release
```

Use `--host opencode` for OpenCode. MCP-only setup omits `--cli-first`.
FFSAKE does not grant permissions; allow the CLI commands and MCP server in
your host policy (for Claude Code, `Bash(ffsake:*)` covers the CLI).

## Compatibility

- macOS ARM64 (macOS 14+) and Linux x86-64 (glibc 2.35+).
- Git for Git operations; Python 3.11+ to run the installer.
- Rust/Cargo and a C compiler only for source builds.
- Language servers and debug adapters are separate optional dependencies.
- Windows is not supported.

## Limitations

- Native Edit/Write changes cannot be undone through FFSAKE.
- Host permissions remain authoritative; task execution is not sandboxed.
- Semantic analysis is explicitly incomplete; language-server acceptance is not
  compiler or semantic correctness.
- The Apple LLDB adapter failed its C++ launch test; use a validated adapter.
- Alpha interfaces may change.
